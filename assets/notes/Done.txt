# Done - 2026-07-08
- fix(lyrics): prevent FOREIGN KEY constraint crash on fast lyric APIs (Heisenbug)
  - Created `saveLyricsSafe` helper in `LyricsFetcher.kt` to catch `SQLiteConstraintException` when saving lyrics.
  - Implemented a 5-second asynchronous retry delay to allow the background audio player enough time to persist the parent `Song` entity before re-attempting the lyrics insertion.
  - Replaced all raw `Database.asyncTransaction { lyricsTable.upsert(...) }` calls with `saveLyricsSafe(...)` to gracefully handle the race condition without data loss or application crashes.
- fix(lyrics): fix erratic scroll offset for multi-line synced lyrics
  - Removed buggy `lineMultiplier` hardcoded values in `SyncedLyricsView.kt` (which pushed 3-line lyrics to 10% from the top and 4-line lyrics to 50%).
  - Standardized the multiplier to `0.35f` for any line count greater than 1, ensuring multi-line translated lyrics remain consistently and smoothly centered.
