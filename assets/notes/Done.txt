Added:
- feat(player): add custom audio device menu with device switching, volume control, and audio quality selection
  - New `AudioDeviceMenu.kt` composable that lists all connected audio devices (Bluetooth, wired, USB, phone speaker)
  - Real-time device detection via `AudioDeviceCallback`, `BroadcastReceiver` for BT connect/disconnect, headset plug events
  - Volume slider with live sync via `VOLUME_CHANGED_ACTION` broadcast receiver; prevents UI desync during manual hardware volume changes
  - `VolumeGridEntry` + `VolumeDialog` in Grid mode, matching the `SliderGridEntry`/`SliderDialog` pattern from `PlaybackSettingsMenu.kt`
  - Audio quality selector (Auto/High/Medium/Low) integrated in both List and Grid menu styles
  - Battery level display for Bluetooth devices via `BluetoothDevice.EXTRA_BATTERY_LEVEL`
  - Supports `menuState.display` pattern (native `BottomSheetMenu`) like all other menus (`PlayerItemMenu`, `SongItemMenu`, `VideoItemMenu`)
  - New `AudioDeviceUtils.kt` with helper functions for device icon mapping and device type resolution

- feat(player): audio device switching with burst prevention
  - `PlayerServiceModern.kt` + `AudioOutputManager.kt`: new `setPreferredAudioDevice(deviceId)` API using `AudioManager.setCommunicationDevice` (API 31+) / `setPreferredDevice` fallback
  - On device switch, playback is paused, volume is polled every 250ms for 3 seconds to let hardware route settle, then playback resumes after ~1s
  - Prevents audio burst caused by volume mismatch when switching between devices with different volume levels (e.g., headphones → phone speaker)

Changed:
- change(player): MiniPlayer audio output button now uses native menu system
  - `MiniPlayer.kt`: replaced `showAudioDeviceMenu` state variable + `CustomModalBottomSheet` with `menuState.display { AudioDeviceMenu(...) }` 
  - Menu now respects status bar padding, background colors, and drag handle styling consistently with all other menus
  - Available on Android 13+ (Tiramisu); Android 10-12 falls back to system `MEDIA_OUTPUT` panel

Fixed:
- fix(player): volume slider not updating on manual hardware device switch
  - Added `isUserDragging` guard to prevent `VOLUME_CHANGED_ACTION` from fighting with user slider input
  - 3-second polling loop after device switch catches delayed OS volume adjustments

Improved:
- improve(ui): audio device menu supports both List and Grid menu styles
  - List mode uses `ListMenu.Menu` with `VolumeRow` inline slider
  - Grid mode uses `GridMenu.Menu` with `VolumeGridEntry` tile that opens a `VolumeDialog` with `SliderControl`
  - Both modes share device selection, volume, and quality sections with consistent styling

Other:
- chore(manifest): added `android.permission.BLUETOOTH_CONNECT` for device discovery on Android 12+
- chore(resources): added `buds.xml` drawable for earbuds device icon
