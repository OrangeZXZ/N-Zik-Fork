## EditMetadataDialog - Metadata Editor for On-Device Songs
- New centralized metadata editor dialog for local songs (reads/writes directly to audio files)
- Uses jaudiotagger with Mp4FieldKey for proper MP4 atom reading (©day, ©wrt, cprt, etc.)
- MMR (MediaMetadataRetriever) fallback for non-MP4 files only
- Logical field ordering: Cover, Title, Artist, Album, Genre, Year, Track, Disc, Album Artist, Composer, Copyright, Comment, Encoder, BPM, ISRC, Publisher, Lyricist, Conductor, Remixer
- Compact cover art layout (56dp image + pick button)
- All standard fields shown even if empty (user can fill in missing metadata)
- Translated field labels via string resources
