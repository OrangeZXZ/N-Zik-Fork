Added:

  - Drops FFmpeg to support older 32-bit devices (`armeabi-v7a`), Media Export is disabled on these builds
  - Updated GitHub CI/CD workflows to automatically assemble and release these new APKs
  - Ensured seamless OTA update support in the native Updater for the new variants

- refactor(easter-egg): replace Pacman and Snake mini-games with static unknown easter egg images

Fixed:
- fix(playback): resolve database corruption/race condition on music playback initialization
  - Immediately persist complete `MediaItem` metadata to the database in `PlayerServiceModern.kt` during `onMediaItemTransition`.
  - Added a check in `StreamResolver.kt` to prevent inserting a blank placeholder `Song` if the song already exists in the database.
- fix(database): resolve Room transaction deadlocks by replacing runBlocking/Flow calls with synchronous DAO queries (`findByIdDirect`, `countById`) to prevent database freezes during playback.
- fix(playback): fix play time stats and history logging for songs played from albums/playlists
  - `PlaybackStatsListener` now correctly splits `mediaItem.mediaId` containing slashes (e.g. `albumId/videoId`) to extract the canonical `songId`, ensuring successful updates to the `Song` table and satisfying foreign key constraints for `Event` history entries.
- fix(search): fix unsafe fallback search in GoToAlbum
  - Removed the unsafe `firstOrNull()` fallback in `GoToAlbum.kt` which resulted in navigating to wrong albums 100% of the time. Now only navigates if there is a strict match on the song ID, and displays a toast error otherwise.
- fix(library): update Artists and Albums library queries to match Songs behavior
  - Changed Room queries in `ArtistTable.kt` and `AlbumTable.kt` so that 'All' library screens fetch based on whether at least one song is liked or played (totalPlayTimeMs >= 1) instead of requiring songs to be mapped to a playlist.
- fix(album): resolve missing album release year
  - Updated `Database.insertIgnore(mediaItem)` to merge new album metadata with existing DB records on song transitions instead of ignoring.
  - Added background resolution: if a song's album does not have a release year in the database, a lightweight background coroutine is launched to fetch the album page and populate the year, description, and share URL automatically.
