## EditMetadataDialog - Metadata Editor for On-Device Songs
- New centralized metadata editor dialog for local songs (reads/writes directly to audio files)
- Uses jaudiotagger with Mp4FieldKey for proper MP4 atom reading (©day, ©wrt, cprt, etc.)
- MMR (MediaMetadataRetriever) fallback for non-MP4 files only
- Logical field ordering: Cover, Title, Artist, Album, Genre, Year, Track, Disc, Album Artist, Composer, Copyright, Comment, Encoder, BPM, ISRC, Publisher, Lyricist, Conductor, Remixer
- Compact cover art layout (56dp image + pick button)
- All standard fields shown even if empty (user can fill in missing metadata)
- Translated field labels via string resources
- UI-only sorting with derivedStateOf (filled fields first by displayOrder, empty last)
- Fixed genre sorting: case-insensitive match via labelFromKey(rawId).uppercase()
- Fixed IndexOutOfBoundsException: indexOfFirst with stable key instead of indexOf

## Metrolist Comparison Analysis
- Stream: Quasi-identical (14 clients, PoToken, cipher, self-healing). NZik has Medium preset extra.
- Download: Equivalent architecture (ExoDownloadService, dual cache, auto-download on like)
- Dependencies: Aligned and up-to-date. NZik uses newer versions (Kotlin 2.4.0, Ktor 3.5.1, Coil 3.5.0)
- Parental Control: Functional but different approach (NZik uses title prefix vs Metrolist uses explicit boolean from API badge)
