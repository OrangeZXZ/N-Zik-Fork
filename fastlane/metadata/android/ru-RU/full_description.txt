<b>N-Zik</b> — ваш идеальный многоязычный клиент YouTube Music для Android с открытым исходным кодом! 🎵🚀

Многоязычный форк <a href="https://github.com/knighthat/Kreate">Kreate</a>, ориентированный на производительность, доработку UI/UX, исправление ошибок и новые функции с долгосрочной поддержкой.

<b>Разработка и стабильность:</b> N-Zik начинался как побочный проект для меня и моих друзей. Он может быть не таким стабильным, как Kreate — обратите внимание на <a href="https://github.com/MetrolistGroup/Metrolist">Metrolist</a>, <a href="https://github.com/vivizzz007/vivi-music">VIVI Music</a> или <a href="https://github.com/fast4x/RiPlay">RiPlay</a> для более зрелых решений.

<b>Прозрачное использование ИИ:</b> Я использую генеративный ИИ для помощи в написании кода (через <a href="https://github.com/bmad-code-org/BMAD-METHOD">метод BMAD</a>), но всё проверяется и тестируется перед выпуском. Не нравится такой подход? Без обид — существует множество отличных альтернатив.

Будь вы обычным слушателем или заядлым аудиофилом, N-Zik дает вам абсолютный контроль над вашей музыкой, не ставя под угрозу вашу конфиденциальность.

✨ <b>ПОЧЕМУ СТОИТ ВЫБРАТЬ N-ZIK?</b> Никакой рекламы, полноценное фоновое воспроизведение, офлайн-кеширование и полностью настраиваемый интерфейс — бесплатно, навсегда.

- Интерфейс на Jetpack Compose с переключателем классического режима ViMusic 🌓
- Кастомные темы: Настоящий AMOLED, Deep Dark, Crisp Light + цветные акценты
- 3D Carousel Player Carousel 🎠 и настраиваемые виджеты на главном экране 🪟
- Подробные профили исполнителей, лента новостей и экспериментальные виджеты 🧪

🎵 <b>Качество звука</b>
- Звук премиум-качества через YouTube Music Premium (клиент Web Remix) 🔊
- Продвинутые синхронизированные тексты песен с редактированием и переводом в реальном времени 🎤
- Аудиовизуализатор в реальном времени 🎇 и профессиональные настройки: скорость, высота тона, нормализация, кроссфейд, усиление громкости 🎚️

💾 <b>Офлайн, метаданные и конфиденциальность</b>
- Умное офлайн-кеширование и загрузка треков и плейлистов 📡
- Экспорт через FFmpeg с полными встроенными метаданными 📤 (только для 64-битных сборок)
- Редактор метаданных в приложении (AAC/Opus, обложка) ✏️
- 100% локальная статистика и история прослушиваний 📊
- Автоматическое резервное копирование с настраиваемыми интервалами и хранением ⚙️

- Вход в YouTube для рекомендаций и переключения аудио/видео 📺
- Discord Rich Presence 🎮
- Импорт/экспорт плейлистов: RiPlay, Spotify (Exportify), YouTube Music, N-Zik 🔄

📱 <b>Слушайте где угодно:</b> Android Auto, Automotive, TV и планшеты 🚗📺

🛠️ <b>Функции для продвинутых пользователей</b>
- Текстовый и голосовой поиск 🎙️
- OTA-обновления через GitHub ⬇️
- Таймер сна и фоновое воспроизведение 💤

🛡️ N-Zik на 100% открыт (FOSS). Основные разрешения: ИНТЕРНЕТ (стриминг/тексты/обновления), RECORD_AUDIO (только для визуализатора, по выбору, никогда не подслушивает), ПАМЯТЬ (экспорт/бэкапы), FOREGROUND_SERVICE/NOTIFICATIONS (воспроизведение), REQUEST_INSTALL_PACKAGES (OTA), BLUETOOTH (беспроводное аудио), WAKE_LOCK (предотвращение остановки воспроизведения).

📦 <b>Доступные сборки</b>
- Full и Beta: Полная сборка со всеми компонентами (только 64-бит)
- Full32 и Beta32: Полная сборка без FFmpeg (32-бит и 64-бит)
- Minified: Облегченная сборка, рекомендуется для слабых устройств (только 64-бит)
- Minified32: Облегченная сборка без FFmpeg (32-бит и 64-бит)
- FOSS: Полная сборка без автообновления, для F-Droid (только 64-бит)
- Dev и Dev32: Сборки для разработчиков из последних коммитов, только для тестирования

Стандартные сборки только 64-битные, так как они включают FFmpeg; в сборках «32» FFmpeg удален для работы на обеих архитектурах. В F-Droid представлена только сборка FOSS.

Начиная с <b>января 2027 года</b> (<a href="https://keepandroidopen.org/en/faq/">почему изменилась дата</a>), Google потребует подтверждения личности от всех Android-разработчиков, даже за пределами Google Play. Как проект свободного ПО с открытым исходным кодом (FOSS), N-Zik и его разработчик выступают против этого требования из-за его влияния на конфиденциальность разработчиков, независимое распространение и свободу ПО.
