📦 <b>Доступні збірки</b>
- Full та Beta: Повна збірка з усіма компонентами (тільки 64-біт)
- Full32 та Beta32: Повна збірка без FFmpeg (32-бит та 64-біт)
- Minified: Полегшена збірка, рекомендована для слабких пристроїв (тільки 64-біт)
- Minified32: Полегшена збірка без FFmpeg (32-бит та 64-bit)
- FOSS: Повна збірка без автооновлення, для F-Droid (тільки 64-біт)
- Dev та Dev32: Збірки для розробників з останніх комітів, тільки для тестування

Стандартні збірки тільки 64-бітні, оскільки вони включають FFmpeg; у збірках «32» FFmpeg видалено для роботи на обох архітектурах. У F-Droid представлена лише збірка FOSS.
