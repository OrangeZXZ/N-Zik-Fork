# Queue Panel Resizable - DONE

## Summary
Replaced `CustomModalBottomSheet` for the queue with a custom inline resizable panel.

## Changes

### New Files
- `QueueToolBar.kt` — `QueueToolBarState` singleton (mediaItemCount, buttons, queueArrow, onBarClick, isVisible) + `QueueToolBar` composable (MiniPlayer + toolbar buttons)

### Modified Files
- `Queue.kt` — Removed bottom bar, populates `QueueToolBarState`, `DisposableEffect` to reset state
- `Player.kt` — Replaced `CustomModalBottomSheet` with inline resizable panel:
  - `Animatable(0.65f)` for height fraction
  - Scrim (black 50% alpha, click to dismiss)
  - Panel with `fillMaxHeight(fraction)`, `align(BottomCenter)`, `clip(RoundedCornerShape(top))`
  - Drag handle at top (48dp, themed background, white indicator line)
  - `QueueToolBar` at bottom with slide-in animation
  - `BackHandler` to dismiss
  - Entry animation: snap to 0 → animate to 0.65
  - Close animation: animate to 0 → set `isQueuePanelVisible = false`
  - Drag logic: >0.85 → expand to maxFraction (status bar aware), <0.4 → close, else → 0.65
  - `nestedScroll` overscroll at bottom of list → drag panel down to close
  - Status bar aware max height (doesn't go above status bar)
  - Theme-aware: Modern (transparent, 50% alpha) / Essential (background2, opaque)
