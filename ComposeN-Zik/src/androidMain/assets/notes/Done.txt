- Added withTimeout(15s) on deobfuscateSignature() and transformN()
- Added failAsRendererGone() and throwIfDead() for proper dead WebView handling
- Added CipherRendererGoneException for renderer death detection
- Updated JS callbacks to pass requestId for stale-result guard
- Fixed withinWindow() usage for cooldowns in PlayerConfigStore
- File: CipherWebView.kt (full rewrite aligned on Metrolist)
- File: PlayerConfigStore.kt (cooldown fix)
